Data movement only

A maintained, exact whitelist of instructions that copy or rearrange existing bits. Arithmetic, comparisons, shifts, branches, calls, and submission-supplied returns are rejected after assembling.

rdi inputrsi outputrdx tablesrcx scratch

One trusted RET is appended by the harness. Masked zeroing and scalar zero/sign extension are permitted by this policy.

How the benchmark works +

A correct, compliant kernel earns 100 points. Each doubling of speed over the task's tier-specific move-only reference earns 25 more. Slower valid kernels retain their 100 points.

100 + 25 × max(0, log₂(reference / candidate))

Native measurements use CPU affinity, warm-up, duration calibration, alternating candidate/reference batches, and exact oracle checks. The median summarizes trial batch means; MAD is not a confidence interval. Results describe a warm-cache, rotating-input workload.

Elo starts at 1,500 with K = 16 over 16 deterministic simultaneous-update rounds; timings within 3% are draws. Rankings use the latest complete run per entrant within the selected hardware and measurement cohort.
